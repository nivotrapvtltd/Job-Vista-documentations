Job Vista - Modern Job Portal Solution

Flutter, Laravel REST API, React Admin Panel

Job Vista is a production-ready job portal solution built with Flutter, Laravel REST API, and a React Admin Panel. It enables organisations, government recruitment portals, private companies, placement agencies, coaching institutes, and career platforms to publish job opportunities, admit cards, results, answer keys, and important notifications through a single, easy-to-manage platform.

The solution includes a Flutter mobile application for Android and iOS, a secure Laravel REST API backend, and a modern React-based administration panel. Designed with scalability, clean architecture, security, and performance in mind, it is suitable for startups, enterprises, recruitment agencies, and government organisations.

Mobile Application Features

User Experience & Auth

  • Secure Email & Mobile OTP Login
  • Registration, Forgot Password, and Profile Management
  • Dark Mode Ready, Responsive UI, Material Design, and Fast Loading

Home Screen & Discovery

  • Promotional Slider Banner & Featured Categories

  • Admit Cards, Results, Answer Keys, and Important Notifications

Job Management & Details

  • Search, Filter, Share, Save Favourite Jobs, and view Similar Jobs
  • Comprehensive Job Details: Title, Organisation, Category, Type, Mode, Location, Qualification, Vacancy Details, Salary, Age Limit, Selection Process, Application Fee, Important Dates, Required Documents, and Official Notification.
  • Push Notifications, Multi-language Ready, Applied Jobs tracking

Admin Panel Features

Analytics & Management

  • Dashboard: Total Users, Active Users, Jobs/Categories/Notifications Statistics.
  • Job & Category Management: Add, Edit, Delete, Draft, Featured, Latest, Government, and Private Jobs.
  • User Management: View, Block, Unblock, User Activity tracking, and Export Users.

Content & Settings

  • Notifications: Push, Scheduled, and Broadcast Notifications.
  • Content Management: Admit Cards, Results, Answer Keys, Online Services, News Updates, and Banner Management.
  • Application Settings: Contact Info, Privacy Policy, Terms and Conditions, Social Media Links, and Email Settings.

Security

Technology Stack & Requirements

  • Mobile Application: Flutter (3.35+), Dart (3.9+), Material Design
  • Backend: Laravel (13+), PHP (8.3+), Sanctum, MySQL (8+), REST API
  • Admin Panel: React (19+), Node.js (22+), Vite, Bootstrap, Axios
  • Server: Apache or Nginx, Shared Hosting / VPS / Dedicated Server, cPanel/Plesk compatible
