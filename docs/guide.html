Introduction

Welcome to Job-Vista, a comprehensive Job Portal platform. Job-Vista provides a robust ecosystem for managing and browsing Government Jobs, Private Jobs, Admit Cards, Results, and Interactive Quizzes.

This documentation will guide you through installing and configuring the three main components of the platform:

  • Backend API: Built with Laravel 13.8 (PHP 8.3).
  • Frontend Admin Panel: Built with React 19.2 (Vite, Material-UI 9.2).
  • Mobile App: Built with Flutter 3.12 (Riverpod, Dio).

Architecture & Flow

Job-Vista operates with a central unified Laravel API servicing both the Web Admin Panel and the Mobile App. The mobile app specifically utilizes a "Dual-OTP" smart-fallback authentication flow, allowing users to verify via WhatsApp or Email seamlessly.

                    graph TD
                        A[Mobile App - Flutter] -->|API Requests| B(Backend API - Laravel)
                        C[Admin Panel - React] -->|API Requests| B

Server Requirements

Ensure your server meets the following requirements before installation:

  • PHP >= 8.3
  • MySQL >= 8.0 or MariaDB >= 10.3
  • Composer v2.x
  • Node.js >= 18.x and NPM >= 9.x
  • Flutter SDK >= 3.12.0 (For Mobile App Compilation)
  • Cpanel / VPS / Dedicated Server for hosting

1. Backend Setup & Deployment (Laravel API)

The backend serves as the core database manager and API provider for both the React Admin Panel and the Flutter Mobile App.

Step 1: Installation

Extract the downloaded package and navigate to the backend directory in your terminal.

cd backend
composer install

Step 2: Environment Configuration

Copy the `.env.example` file and rename it to `.env`.

cp .env.example .env

Open the `.env` file and configure your database settings:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password

Step 3: App Key & Database Migration

Generate the application key and run the database migrations along with the seeders to insert default admin credentials.

php artisan key:generate
php artisan migrate --seed

Step 4: Storage Link & Run

Link the storage folder to make uploaded files (like profile pictures and PDFs) publicly accessible.

php artisan storage:link

Production Deployment (cPanel / VPS)

Option 1: Recommended (More Secure)

1. Upload the entire backend folder to your server in a directory outside public_html (e.g., /home/user/job-vista-api).

2. Point your subdomain or domain's Document Root directly to the public folder (e.g., /home/user/job-vista-api/public).

Option 2: Shared Hosting (Inside public_html)

If your host requires files inside public_html, upload the backend contents to a folder like public_html/api.

Create a file named .htaccess in that folder (e.g., inside public_html/api) and add this code to route all requests to Laravel's public directory without showing "public" in the URL:

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>

Final Checks: Ensure proper file permissions (755 for directories, 644 for files) and run php artisan storage:link.

2. Admin Panel Setup & Deployment (React)

The frontend provides a sleek Material-UI dashboard to manage Jobs, Quizzes, Categories, and App users.

Step 1: Installation

Navigate to the frontend directory.

cd frontend
npm install

Step 2: Configuration

Open the .env file (or create one) in the frontend directory and point the API URL to your live backend domain.

VITE_API_URL=https://api.your-domain.com/api

Step 3: Build & Deploy to Production

To compile the optimized production code, run:

npm run build

This will generate a dist folder containing the static HTML/JS/CSS assets.

Upload the contents of the dist folder to your web server (e.g., inside public_html/admin for cPanel). Ensure you configure Apache/Nginx to handle React routing (e.g., rewriting all requests to index.html).

3. Mobile App Setup (Flutter)

The Flutter app provides a premium UI/UX for end-users to browse jobs, apply, and take quizzes.

Step 1: Install Dependencies

Ensure you have Flutter installed. Navigate to the mobile directory.

cd mobile
flutter pub get

Step 2: API Configuration

Open lib/core/constants/api_endpoints.dart (or your specific network configuration file) and update the base URL to point to your live Laravel API.

class ApiEndpoints {
  static const String baseUrl = 'https://api.your-domain.com/api';
  // ...
}

Step 3: Run / Build

Run the app on an emulator or connected device:

flutter run

To build an APK for Android release:

flutter build apk --release

To build an AppBundle for Google Play Store:

flutter build appbundle --release

4. Customization Guide

Changing the App Icon & Splash Screen (Mobile)

We use automated libraries (flutter_launcher_icons and flutter_native_splash) to effortlessly generate your icons across all platforms.

  1. Replace the brand_png.png file inside mobile/assets/brand/ with your square logo (1024x1024 recommended).
  2. Replace the splash.png file inside mobile/assets/brand/ with your splash screen logo.
  3. Run the following commands to generate the assets: 
    cd mobile
dart run flutter_launcher_icons
dart run flutter_native_splash:create

Changing the Package Name (Android)

The easiest way to change the package name (e.g., com.yourcompany.jobvista) is to use the rename package.

  1. Run the following command globally: 
    flutter pub global activate rename
  2. Navigate to the mobile directory and apply your new bundle ID: 
    cd mobile
flutter pub global run rename setBundleId --value "com.yourcompany.appname"

Changing the App Name (Display Name)

You can also use the rename package to change the display name of your app effortlessly:

flutter pub global run rename setAppName --value "Your App Name"

Key Features

  • Smart Dual-OTP Authentication: Users can verify themselves using either their WhatsApp OTP or Email OTP interchangeably during the login and registration flows.
  • Job Management: Easily categorize Govt and Private jobs with extensive details (Salary, Age Limit, Links, Documents).
  • Interactive Quizzes: Create dynamic multiple-choice quizzes from the admin panel that users can play natively in the app.
  • Premium UI: Built with cutting-edge Glassmorphism designs and fluid animations across Login, Registration, and internal dashboard pages.
