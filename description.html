Job Vista v1.0.2 | Flutter Job Portal App with Laravel API and React Admin Panel

Built for Retailers, Kiosk Operators, CSC Agents, Cyber Cafes & Jan Seva Kendra — Assisted Job & Service Application Platform

Job Vista is a complete, self-hosted job-assistance platform built for retailers, kiosk operators, CSC (Common Service Centre) agents, Cyber Cafes, and Jan Seva Kendra operators who help walk-in customers apply for government jobs, private jobs, PAN cards, Aadhaar, exam registrations, and other civic services — charging a small service fee on top of the official government fee.

The platform includes a Flutter mobile app (customer-facing), a React admin panel (operator dashboard), and a Laravel 12 REST API (backend) — all communicating over a single JSON API. Full source code for all three components is included.

Who Is This For?

Job Vista solves a real problem: millions of citizens — especially in semi-urban and rural areas — need help navigating government portals to apply for jobs, exams, PAN cards, Aadhaar updates, and other services. They visit a local Cyber Cafe, CSC center, or kiosk and pay the operator (government fee + service charge) to handle the application on their behalf.

  • Retailers & Kiosk Owners — Offer form-filling services as a revenue stream
  • CSC / Jan Seva Kendra Agents — Government-authorized service point operators
  • Cyber Cafes — Internet centers assisting customers with online government and private applications
  • Form-Filling Centers — Dedicated centers for PAN card, Aadhaar, driving licence, job, and exam applications

What Services Operators Can Offer

  • Government job applications — SSC, Railway, Banking, UPSC, Police, Defence
  • Private sector job applications — IT, BPO, manufacturing, retail
  • Admit card downloads and result checking
  • Exam preparation quizzes for customers
  • Other civic services — PAN card, Aadhaar, driving licence, certificates (via the Other Services module)
  • News, alerts, and job notifications

Flutter Mobile App Features

  • OTP login via WhatsApp or SMTP Email — no password required
  • Secure authentication token storage using Android Keystore and iOS Keychain
  • Government and private job listings with full details: salary, age limit, eligibility, selection process, application fee, important dates, required documents, and official links
  • Search and filter jobs by category, type, and keyword
  • Save jobs for later, track applied jobs
  • Admit card downloads and exam result checking
  • Multiple-choice quiz module for exam preparation
  • Push notifications via Firebase FCM
  • News and article reader
  • Other Services — submit requests for PAN, Aadhaar, DL, and other civic services
  • CMS pages — Privacy Policy, Terms & Conditions, About Us
  • Home banner slider, featured categories, and profile management

React Admin Panel Features

  • Dashboard: Summary counts — total users, active users, jobs, applications, categories
  • Job Management: Create, edit, publish, draft, and delete listings with full detail fields (salary, vacancies, age limit, selection process, links, fees, tags, documents)
  • Category Management: Govt, Railway, Banking, Defence, IT, and custom categories
  • Admit Cards & Results: Publish download links and result check links
  • Quizzes: Create multiple-choice quizzes with questions and correct-answer tracking
  • Other Services: Define and manage service types; view all customer service requests
  • User Management: View, activate, deactivate, and export users to CSV
  • Notifications: Create and send push notifications to all users
  • Content: Banners, posts/articles, and CMS pages
  • Settings: OTP (WhatsApp), Firebase, SMTP Email, Contact Details — with live SMTP test delivery
  • System Update: Install official signed backend update packages (super admin only)
  • Reports: Application and usage data views

Laravel API Features

  • PHP 8.2+, Laravel 12, Laravel Sanctum authentication
  • Separate admin and user authentication tables
  • RESTful JSON API consumed by both the admin panel and mobile app
  • Channel-aware OTP delivery — WhatsApp and/or SMTP email, configurable per deployment
  • Signed backend update system with Ed25519 signature verification and SHA-256 checksums
  • Web installer — guided setup wizard for fresh deployments (no CLI required)
  • Demo mode — full content lock for safe public demonstrations

Technical Requirements

  • PHP: 8.2 or later
  • Laravel: 12.x
  • MySQL: 8.0 or later
  • Node.js: 18.x or later (for building admin panel only)
  • Flutter SDK: 3.24.x or later
  • Dart SDK: 3.5.x or later
  • Android SDK: API 36 compile and target SDK
  • Mobile application identifier: com.jobvista.app (Android and iOS)
  • Composer: 2.x
  • Required PHP extensions: OpenSSL, PDO, PDO_MySQL, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath, Fileinfo, cURL, ZIP, Sodium
  • Server: Apache with mod_rewrite or Nginx — Shared Hosting / cPanel / VPS / Dedicated Server compatible

Security

  • Laravel Sanctum bearer token authentication for both admin and user APIs
  • Separate admin and user authentication tables
  • Hardware-backed secure token storage — Android Keystore and iOS Keychain
  • Ed25519 signed update packages with SHA-256 per-file checksums
  • OTP-based login — no stored passwords required for end users
  • Demo mode — server-side enforcement blocks all writes in public demos
  • Web installer locks after completion — cannot be re-run from the browser
